# Purpose

This document serves as the official creative brief for designing Portfolio OS.

It should be used by designers, AI design assistants and future collaborators to generate interfaces that remain visually and functionally consistent.

The objective is not simply to design a portfolio.

The objective is to design an operating system dedicated to showcasing the creative work of Carlo Desantis.

Every screen, interaction and component should reinforce that illusion.

---

# Project Vision

Portfolio OS is a creative operating system.

Visitors should feel as if they have opened Carlo Desantis' personal computer rather than visiting a conventional website.

The experience should encourage exploration.

Projects are discovered naturally through interaction.

The operating system itself becomes the storytelling medium.

# Emotional Goals

The interface should feel:

Elegant

Minimal

Creative

Editorial

Calm

Premium

Human

Playful when appropriate

Professional at all times

Visitors should immediately perceive a high level of craftsmanship.

# Core Experience

The desktop is the home.

Applications open inside windows.

Windows reveal creative work.

Creative work becomes the primary focus.

Navigation should never feel like browsing pages.

Navigation should feel like using software.

---

# Target Devices

Desktop

Primary experience.

Tablet

Desktop adapted to touch.

Mobile

Native iPhone-inspired operating system.

Every experience should share the same design language while respecting the strengths of each device.

The desktop contains:

Cursor

Minimal.

Elegant.

Inspired by macOS.

Apple-style system menu

Contains:

Finder

Work

Spotify

Instagram

Figma

# Finder

Finder is the heart of the portfolio.

Users browse folders naturally.

Categories include:

Music

Fashion

Advertising

Branding

Photography

Personal Projects

Folders should open with elegant motion.

Navigation should preserve orientation.

---

# Work Presentation

Projects should feel cinematic.

Large imagery.

Minimal interface.

Generous whitespace.

Elegant typography.

Media should always remain the primary focus.

Metadata supports the content.

Never competes with it.

---

# Widgets

Widgets communicate personality.

Initial widgets include:

Spotify

Photography

Notes

Recent Projects

Clock

Quote

Widgets should remain glanceable.

Interaction opens full applications.

---

# Spotify Widget

Display:

Playlist artwork

Currently playing track

Artist

Playback controls

Progress

Eventually integrate Spotify APIs.

The widget should feel alive without becoming distracting.

---

# Photography Widget

Automatically cycles through curated photography.

Images should transition smoothly.

Subtle motion only.

Opening the widget launches Photos.

---

# Notes Widget

Displays a selected quote.

Opening the widget launches Notes.

Notes contain:

Biography

Manifesto

Creative Philosophy

Journal

---

# Window System

Windows should feel native.

Rounded corners.

Glass materials.

Blur.

Soft shadows.

Resizable.

Draggable.

Persistent.

Window management should feel intuitive.

---

# Motion

Motion should follow MOTION.md.

Animations should explain relationships.

Avoid decorative movement.

Transitions should feel effortless.

Every animation should preserve spatial awareness.

---

# Materials

Use subtle glass.

Translucency.

Layering.

Depth.

Soft shadows.

Never exaggerate visual effects.

Content always remains readable.

---

# Color

Neutral palette.

Subtle accents.

Minimal saturation.

Interaction colors only where necessary.

The interface should remain timeless.

---

# Typography

Inspired by Apple's hierarchy.

Large editorial headlines.

Comfortable body text.

Minimal font variation.

Readable at every size.

---

# Grid

Desktop

12 columns.

Tablet

8 columns.

Mobile

4 columns.

Spacing should follow DESIGN_SYSTEM.md.

---

# Iconography

Simple.

Consistent.

Balanced.

Minimal.

Prefer custom icons when appropriate.

Avoid mixing icon styles.

---

# Cursor

Cursor interactions are part of the experience.

Hover previews.

Media previews.

Magnetic interactions.

Loading states.

Cursor should communicate intent.

---

# Wallpaper

Wallpaper defines mood.

It should be cinematic.

Minimal.

Not distracting.

Support future wallpaper themes.

---

# Accessibility

The interface should remain usable by everyone.

Keyboard navigation.

Reduced motion.

High contrast.

Screen readers.

Large touch targets.

Accessibility is a design requirement.

---

# Performance

Visual quality should never compromise performance.

The interface should remain fluid.

Animations should maintain 60 FPS.

Heavy effects should be used only when justified.

Performance is part of aesthetics.

---

# Design Rules for Contributors

All design contributors must prioritize clarity, consistency, and usability above all else.

Do not invent unnecessary interface elements.

Do not introduce visual trends without purpose.

Respect every document contained inside the docs folder.

Design decisions should be based on user experience rather than aesthetics alone.

The goal is to create a timeless product that could evolve for many years.

See [CLAUDE.md](CLAUDE.md) for the complete collaboration guide and vocabulary.

---

# Final Objective

Create an operating system that feels believable.

Visitors should remember the experience because of its quality, not because of unnecessary visual effects.

The interface should disappear behind the creative work.

Every screen should communicate craftsmanship, precision and personality.

Portfolio OS should become a benchmark for creative portfolio design.
