# macOS Desktop Reference

## Overview

This directory contains a complete macOS-inspired desktop prototype used exclusively as a design and interaction reference for the Carlo Desantis portfolio.

The reference consists of a single HTML file containing its HTML structure, CSS styles and JavaScript logic.

It is **not** part of the production codebase.

Its purpose is purely educational and architectural.

---

# Files

reference.html

Contains:

- HTML
- CSS
- JavaScript
- SVG assets
- Window management
- Dock interactions
- Menu bar
- Boot animation
- Desktop layout

pen.config.json

Contains the original CodePen configuration metadata.

This file should not influence the project architecture.

---

# Purpose

The Carlo Desantis portfolio aims to become an operating system experience rather than a traditional website.

This reference demonstrates many interaction patterns that successfully recreate the feeling of using macOS inside a browser.

It should be studied to understand interaction design rather than implementation details.

---

# What Should Be Studied

The following systems should be analyzed carefully.

## Boot Experience

Study:

- startup animation
- Apple logo
- loading sequence
- timing
- visual rhythm

The final portfolio should include its own premium startup animation inspired by modern macOS.

---

## Desktop Environment

Study:

- desktop composition
- icon positioning
- spacing
- hierarchy

The final implementation should be significantly cleaner and more minimal.

---

## Menu Bar

Study:

- transparency
- layout
- spacing
- interactions

The implementation should follow Apple's latest Human Interface Guidelines.

---

## Dock

Study:

- hover effects
- magnification
- spacing
- motion
- interaction timing

The final dock should become one of the highest-quality components of the entire application.

---

## Window System

Study:

- opening
- closing
- focus
- dragging
- resizing
- stacking
- transitions

The production version should feel closer to native macOS than this prototype.

---

## Motion

Observe every animation.

Study:

- easing
- duration
- sequencing
- continuity
- interaction feedback

The goal is understanding motion design principles.

Never reproduce animations one-to-one.

# Technical Analysis

The reference was built using:

- HTML
- CSS
- Vanilla JavaScript
- jQuery
- jQuery UI

These technologies are considered legacy for this project.

The production implementation must instead use:

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion

No jQuery should ever be introduced into the project.

---

# What Must Never Be Copied

Never reuse:

- HTML structure
- CSS
- JavaScript
- Variables
- Class names
- Architecture
- Business logic

Everything must be reimplemented from scratch.
