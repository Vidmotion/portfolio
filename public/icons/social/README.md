# Social glyphs

Instagram and LinkedIn path data come from Simple Icons 9.21.0:

- https://cdn.jsdelivr.net/npm/simple-icons@9.21.0/icons/instagram.svg
- https://cdn.jsdelivr.net/npm/simple-icons@9.21.0/icons/linkedin.svg
- Upstream: https://github.com/simple-icons/simple-icons/tree/9.21.0

Local copies use a silver `#eef0f4` fill to match the portfolio's glass tiles.
The path data are unchanged. Brand names and marks belong to their respective owners.
Carlo's custom portfolio icons remain separate editable masters.
